# Personal Task Manager

A Laravel Personal Task Manager created for the WST21 Mini Project.

## Project Information

Project Code: WST21-PM-2026-SF

Student Name: SADAYA, NIÑA JANE P.

Course & Year: BSIT-2

Database Used: MySQL

## About the Project

This Personal Task Manager helps users manage their daily tasks through a simple and organized dashboard.

Users can add tasks, view saved tasks, edit task details, update task status, and delete tasks that are no longer needed.

Each task includes a task name, optional description, status, and due date.

## Features

- Add Task
- View Tasks
- Edit Task
- Delete Task
- Update Status
- Pending
- Completed

## Technologies Used

- Laravel
- PHP
- MySQL
- Blade
- HTML
- CSS
- Git
- GitHub Codespaces

## Laravel Process

The project follows this Laravel workflow:

Route → Controller → Model → Database → Blade View

The route receives the request, the controller processes the task operation, the model communicates with MySQL, and the Blade view displays the result.

## Main Task Fields

- ID
- Task Name
- Description
- Status
- Due Date
